# aiSarthi project continuity

- Before resuming development, read README.md, PROJECT_STATUS.md, and ROADMAP.md,
  then inspect the current repository state. Historical validation is evidence,
  not proof that the current checkout still passes.
- ROADMAP.md is the prioritized upcoming backlog. When asked to continue, start
  with its first incomplete goal unless the user selects a different scope.
- Preserve the Bun/Next.js/MongoDB architecture, existing UI, and user changes.
- Implement one bounded goal, verify the relevant behavior, and update its status
  and PROJECT_STATUS.md with evidence, limitations, and the exact next step.
- Keep fixture-tested app behavior separate from live provider verification.
  Backlog entries alone do not authorize new account access, broader permissions,
  provider requests, or deployment.
